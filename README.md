# 实时攻略查看器（HOI4 1.19 决议指南模组）

内容来自《萌新向军备设计攻略（1.19）》（作者：食言者当受食炎之罚 / 牢绯工坊），
以游戏内决议 + 事件的形式整理为一份随时可查的开局参考。
模组界面支持简体中文与英文；游戏切换为英文时会自动加载英文文本。

## 安装

1. 将整个 `MengXin_Armaments_Guide` 文件夹复制到：
   `C:/Users/<用户名>/Documents/Paradox Interactive/Hearts of Iron IV/mod/`
   （本机若使用 OneDrive 重定向，则放入 OneDrive 中对应的 `mod` 文件夹）。
2. 将 `MengXin_Armaments_Guide.mod` 也放入同一个 `mod` 文件夹。
   若启动器找不到，可把该 `.mod` 里的 `path` 改成实际文件夹路径。
3. 在 Paradox 启动器中启用本模组后开始一局新游戏。

## 使用

- 开局后在“决议”面板中即可看到分组：`学说与编制，设计推荐`。
- 分组内包含七个决议：陆军学说、海军学说、空军学说、陆军编制、坦克设计、
  飞机设计、舰船设计。
- 点决议会弹出该主题的菜单事件；每个详细页面都配原攻略截图，并提供：
  - `了解了`：关闭事件；
  - `我还想看看其他的`：返回当前主题的选项页，继续查看其他条目。
- 坦克、舰船、飞机设计每页只展示一张对应图片。完整成品、局部界面、转换前参考和相关方案会分别标注，避免把图片中的原始角色名称误当成最终设计类型。
- 坦歼首页使用PPT第56页真正的坦歼成品；第55页仍标注“中型坦克”的两图仅作为切换坦歼角色前的加农炮参考。自行火炮实图均标为轻型自行火炮，不虚构中自火图片。
- 多个真实方案通过“上一张图 / 下一张图”切换；没有相邻图片时不会显示对应翻页选项。

## 兼容性

- 面向 HOI4 1.19.x；不依赖任何 DLC 或其它模组。
- 模组覆盖普通事件窗口布局：1140×680，上方为说明，左侧为攻略图片，右侧为事件选项。
- 从原始 PPT 提取截图，裁掉外围黑边，等比例缩放至 720×450 图片区域；空余区域透明，保留截图内部的深色面板。
- 建议有效界面分辨率至少为 1280×720；较高 UI 缩放可能需要调低缩放比例。
- 同样覆盖 `interface/eventwindow.gui` 的界面模组可能冲突；普通原版事件也会使用此布局，共用按钮字体和尺寸也有调整。
- 原攻略截图仅作为模组内容随附展示，禁止在模组外二次分发原图。
