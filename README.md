# 实时攻略查看器（HOI4 1.19）

在游戏内通过独立攻略窗口随时查阅学说、编制与装备设计。
坦克章节按《1.19.4坦克攻略.docx》整理；陆军编制按《1.19.4步兵设计攻略.docx》重建。
飞机章节按《1.19.4飞机设计攻略.docx》更新，36套设计均补齐武器、引擎与特殊配件说明。
陆军学说、精神和支援说明以2026年10月27日官方1.19.4日志优先，再参考原PPT文字。
原有章节资料来自《萌新向军备设计攻略（1.19）》（食言者当受食炎之罚 / 牢绯工坊）。
新坦克资料由用户提供，文档中的参考设计来自钢四 ocea。

## 安装与打开

1. 将所选模组文件夹及对应 `.mod` 文件放入 HOI4 用户目录的 `mod` 文件夹，或让 `.mod` 的 `path` 指向本机开发目录。
2. 本次仅更新 `MengXin_Armaments_Guide`。启动器中请启用指向此目录的模组，同名中文副本未同步此次更新。
3. 完全重启游戏并进入对局后，点击屏幕左下方“攻略查看器”（英文为“Guide Viewer”），再选择所需章节。可自行暂停后浏览。

使用创意工坊订阅版时，等待 Steam 下载完成，再在启动器播放集中启用工坊版。开发者测试自己的订阅版时，应先备份并移出用户 `mod` 扫描目录中的同名本地登记及旧副本；仅取消勾选或修改本地登记的显示名可能不足，启动器还可能重新写回名称。正常的 D 盘源码目录可保留在扫描范围之外。

已确认的一次加载故障表现为：本地版校验码为 `7e3d`，工坊版仍为原版 `f584` 且没有攻略按钮。完整隔离重复本地登记与旧副本后，工坊版变为 `7e3d`，按钮正常出现。这是该安装环境的结果；同时启用其他模组时，校验码可以不同。

按住入口按钮左侧的点阵把手拖动，可将整组入口移动到屏幕其他位置。右侧“攻略查看器”按钮保持原来的大小、样式和点击打开功能。

1.1.0版改为独立界面：攻略入口从决议栏移到上述按钮，原有全部攻略、目录跳转和放大视图保留。

支持简体中文与英文。英文下通过“Division Templates: 1.19.4”和“Army Doctrine: 1.19.4”打开更新后的陆军章节；18套编制、学说、精神、支援说明及导航均有英文文本。原始配置图保留中文游戏界面，配套说明卡为中英双语。

## 兼容性与验证

- 查看器没有 DLC 或其他模组依赖；实际复现某些设计仍需相应游戏功能和科技。
- 描述符当前标注1.19.4.1，本机安装版本也是1.19.4.1。
- 独立攻略窗口使用1140×680完整背景；左侧720×450图片，右侧最多八个选项。建议有效界面分辨率至少1280×720。
- 更新界面后请完全退出并重启游戏，避免界面热重载保留旧控件。
- 本模组不再覆盖 `interface/eventwindow.gui`，也不再加载攻略决议或国家事件。原版事件窗口、补给、海运、港口、单位和AI规则不作改写。
- 浏览只使用本模组私有的页码与按钮数变量；关闭攻略时两者都会清除。
- 静态检查与离线排版已完成；用户已确认工坊版正常加载并显示攻略入口。拖动、全部页面点击及高 UI 缩放下的显示尚未完整实测。
- 原有攻略图片的使用范围仍限于本模组，原图不得在模组外二次分发。

关于登陆补给反馈的排查结论和隔离边界见 `MECHANICS_ISOLATION_REPORT.md`；维护说明见 `TECHNICAL_GUIDE.md`，变更与验证记录见 `DEVELOPMENT_HANDOFF.md`。
